3D-printable shadow-box frame for a 9x12in witch illustration: concave bat-wing sides with flared corner tips, a face sloping from a thin outer edge into a deep sightwell, and a rabbet with snap-in flex prongs for the art stack.

Generated by `blend print-pack` (2026-10-17T10:09:36-04:00), spec `print-spec/1`. Units **mm** (1 Blender unit
= 1 mm). Material PETG (Insignia, black). Bed 256 mm.

## Assembly
- One corner (TR) of the mitered frame and the hanger: Coupon_T (Rail_T's end, with the T+75 prong slot), Coupon_R (Rail_R's end) and Coupon_M (Rail_T's middle, with the hanger slots), plus the key, spline, prong and Hanger.
- Spline: push it into Coupon_R's socket, then close Coupon_T across the miter. The miter line on the face should be flush; note any step or rock.
- Key: press it into the back pocket across the miter until both arms click. Try to pull the corner apart and note how it fails.
- Prong: set a scrap of the real backboard (and glazing if handy) in the rabbet, then push the prong's tongue into Coupon_T's slot until the barbs click. The bump should press the stack firmly against the lip. Note the click, how hard it is to pull out, and how hard it presses.
- Hanger: snap it into Coupon_M's two slots. Drive the nail you'll hang with into scrap wood, head ~1.8 mm proud, hook the keyhole over it and slide down: the head should pass the round entry, run up the slot and hold behind the lip. Hang Coupon_M from it and tug; note if the head binds, the lip flexes or a tongue lets go.
- Log each fit with /bambi:print-log (tight / good / loose) so the next pass can tune CLEAR, BARB, SNAP_*, PRONG_BUMP and HANGER_*.

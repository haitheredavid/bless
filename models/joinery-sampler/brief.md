# joinery-sampler

## Intent
A working, printed reference for common 3D-printed (FDM) joinery. Each joint joins two standard bars (18 × 18 × 25 mm per half by default) with its code and clearance engraved, so the set can be handled, compared and kept as a physical swatch. Every joint is generated by a reusable joint library in `lib/patterns/joints/`, so later models (frames, enclosures) drop the same, printer-calibrated joints in.

Families in scope: **Interlocking**, **Pins & tenons**, **Snap & twist**. Hardware (nut traps, inserts, magnets) and motion (hinges, threads) are out of scope for now.

| Code | Joint | Family | Loose part | Sweep (mm per face) |
|---|---|---|---|---|
| DT | Sliding dovetail | Interlocking | - | 0.15 / 0.20 / 0.30 |
| TD | Tapered dovetail | Interlocking | - | 0.10 / 0.15 / 0.20 |
| FJ | Finger / box | Interlocking | - | 0.10 / 0.20 / 0.30 |
| PZ | Jigsaw / puzzle tab | Interlocking | - | 0.10 / 0.15 / 0.20 |
| BK | Butterfly key | Interlocking | key | 0.05 / 0.10 / 0.15 |
| HL | Half-lap | Interlocking | - | 0.10 / 0.20 / 0.30 |
| DW | Alignment dowel | Pins & tenons | pin | 0.15 / 0.20 / 0.25 |
| PF | Press-fit pin | Pins & tenons | pin | -0.05 / -0.10 / -0.15 |
| MT | Mortise & tenon | Pins & tenons | - | 0.10 / 0.15 / 0.20 |
| LT | Loose tenon, 45° gable roof | Pins & tenons | tenon | 0.10 / 0.15 / 0.20 |
| CH | Cantilever snap hook | Snap & twist | - | 0.10 / 0.15 / 0.20 |
| AS | Annular snap | Snap & twist | - | 0.10 / 0.15 / 0.20 |
| BY | Bayonet twist-lock | Snap & twist | - | 0.15 / 0.20 / 0.30 |

Starting sweeps come from published FDM clearance guides (Qidi interlocking-parts guide, Hubs, Formlabs) and witch-frame's coupons (0.10 slid, 0.15 snap). The prints replace them.

## Requirements
- Bambu P1S, 256 mm bed, 0.4 mm nozzle, 0.2 mm layers, PETG. Model in mm, z=0 floor.
- Bar half 18 × 18 × 25 mm default (params). `WALL = 2.4` mm minimum plastic around any recess (6 lines), asserted.
- Clearance is per mating face. **A is nominal; B carries the clearance.** One A tests three B's: 4 parts per joint. Loose joints (key, pin, tenon) carry it in both bars' sockets, so they print an A+B pair per clearance plus one nominal loose part (7 parts).
- FDM rules built into every joint: 0.4 mm chamfer on male edges (elephant's foot), 0.5 mm end gap in blind sockets, 45° gable roof on any horizontal tunnel, `supports = "none"` on every part as the target.
- Snap arms: t ≥ 1.0 mm (PETG), L/t ≥ 3, layers along the arm. Press-fit interference ≤ 0.15 mm.
- Engraved label on the front (-y) face, 0.4 mm deep, font size 4.5: code + clearance (`DT .15`, `PF -.05`) on B and on loose-joint bars, `DT A` on a nominal A. Loose parts are unlabelled (too small; identity is obvious).
- One print pack per family; each part fits the bed; the whole set checks `--strict` clean.

## Plan
- **Library** `lib/patterns/joints/` (registered in `patterns.ALL`):
  - `joint_bar` → `GN_JointBar`: bar + edge chamfer + engraved label (Bar Width/Height/Length, Edge Chamfer, Label, Label Size, Label Depth).
  - `joint_<kind>` → `GN_Joint_<Kind>`, one per joint, shared contract: `Part` (0 = A, 1 = B, 2 = Loose), `Clearance` (grows B/sockets only), `Joint Origin`, `Joint Rotation` (host-local; mating axis +X, joint face at the origin), plus prefixed size inputs (`Dovetail Angle`, `Tenon Width`, ...).
  - `_common.py`: clearance offset, chamfer, gable roof, A/B/Loose switch.
- **Control:** `CTL_Board` (empty, display board origin); `CTL_Puzzle_Profile` (Bezier knob outline, user-reshapable).
- **Builders:**
  - `catalog.py` (helper): the single joint list (code, pattern, family, `fit`, `sweep`, print-spec kind, loose, orientation why, GN overrides) plus `validate(p)` wall checks. `fit` is the clearance the board shows and later models reuse; the coupon param points at it.
  - `10_board.py`: Model display board, one assembled pair per joint at base clearance, a row per family, `Explode` input.
  - `20_print.py`: `Print_Interlock`, `Print_Pins`, `Print_Snap` collections with the sweep parts, `obj["joints"]` metadata.
- **Params:** `[base]` bar size, chamfer, label, per-joint GN sizes (`Dovetail *`, `Key *`), `Explode`. Clearances are not params (catalog). Variants `slim` (16 mm bars; BK walls drop below WALL, view only), `chunky` (22 mm), `dt_steep` (dovetail 20°), `exploded`.
- **Sessions:** 1. `GN_JointBar` + contract, DT and BK, board row 1, `Print_Interlock` pack for DT/BK. 2. TD, FJ, PZ, HL. 3. Pins & tenons (LT promoted from witch-frame `joinery.py`). 4. Snap & twist. 5. Print results round trip, distill `workflows/printed-joinery.md` with measured clearances.
- **Open:** bambi's print-spec joint kinds lack dovetail / finger / puzzle / half-lap / bayonet; decide at first pack whether to extend the spec in `../bambi` or map to the nearest kind.
- **Verify:** `just check joinery-sampler`; `blend check joinery-sampler --collection Print_<Family> --strict`; `validate(p)` (walls, snap t and L/t, interference); a raycast that each B socket's gap matches its label; `just print-pack` exits 0. Views: `hero`, `plan`, later `row_<family>` and a live `section` through the assembled joints.

# joinery-sampler: print pack

PETG reference set of common FDM joints (interlocking, pins & tenons, snap & twist): each joint is a matched pair of labelled 18 mm bars, one nominal A against three B's swept over clearance, generated by a reusable joint library (lib/patterns/joints) that later models reuse.

Generated by `blend print-pack` (2026-10-17T11:04:50-04:00), spec `print-spec/1`. Units **mm** (1 Blender unit
= 1 mm). Material PETG. Bed 256 mm.

- `parts.blend`: only the printable parts, modifiers applied, each on the bed (z=0), laid
  out without overlaps. Open it as the printing session's model.
- `stl/`: one STL per part (mm).
- `manifest.json`: this information, machine-readable.

Orientation: as modelled: each part's lowest face is on the bed (z=0).
